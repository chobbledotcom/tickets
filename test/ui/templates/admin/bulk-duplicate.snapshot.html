Duplicate Group

Creating a new group based on Summer <Crew>. Each listing in the group will be duplicated into the new group with the same settings. Use the fields below to apply a name replacement and/or a date shift across all duplicates.

Enter a reference date that appears in the current listings and the date you want it to become. All listing dates (and closing times) will be shifted by the same number of days.
