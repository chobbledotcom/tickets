# A shape is a coarse thing: build an object from another object's fields, map
# then join, compare two fields with `&&`. Enough code does that for two
# unrelated functions to match without either being a copy of the other.
#
# A line belongs here only when there is no shared step to lift, and only when
# no two of its sites are a pair. When in doubt, try writing the curry first —
# "these two cannot be merged" is nearly always wrong, and this file is the one
# place that judgement is recorded.
